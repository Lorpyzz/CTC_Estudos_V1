Tipos Abstratos de Dados
TAD (Tipo Abstrato de Dados) separa a interface (o quê) da implementação (como).
Princípios:
• Encapsulamento:: dados internos são ocultos
• Interface pública:: funções que o usuário pode chamar
• Implementação privada:: detalhes internos
Em C, usando ponteiros opacos:
typedef struct lista Lista;
Lista* lst_criar(void);
void lst_inserir(Lista* l, int val);
int lst_remover(Lista* l);
void lst_destruir(Lista* l);
Vantagens:
• Mudança de implementação não afeta clientes
• Facilita manutenção e testes
• Permite múltiplas implementações da mesma interface
