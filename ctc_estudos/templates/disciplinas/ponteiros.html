Ponteiros e Alocação Dinâmica
Ponteiros são variáveis que armazenam endereços de memória. Em C, declaramos um ponteiro usando o operador *. Por exemplo: int *p; declara um ponteiro para inteiro.
Operadores fundamentais:
• & (endereço de): obtém o endereço de uma variável
• * (desreferência): acessa o valor apontado
Alocação dinâmica:
• malloc(size): aloca 'size' bytes na heap
• calloc(n, size): aloca e inicializa com zero
• realloc(ptr, size): redimensiona bloco alocado
• free(ptr): libera memória alocada
Exemplo:
int *arr = (int*)malloc(10 * sizeof(int));
if (arr == NULL) { printf("Erro de alocação"); exit(1); }
for (int i = 0; i < 10; i++) arr[i] = i * 2;
free(arr);
Sempre verifique se malloc retornou NULL e sempre libere a memória com free para evitar memory leaks.
