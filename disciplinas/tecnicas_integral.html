Técnicas de Integração
Técnicas principais de integração:
1. Substituição (u-sub):: ∫f(g(x))g'(x)dx = ∫f(u)du
Exemplo: ∫2x·cos(x²)dx → u=x², du=2xdx → ∫cos(u)du = sin(u)+C
2. Integração por partes:: ∫udv = uv - ∫vdu
Escolha u pela regra LIATE (Log, Inversa trig, Algébrica, Trig, Exponencial)
3. Frações parciais:: Decomponha frações racionais em frações mais simples
4. Substituição trigonométrica:
- √(a²-x²): x = a·sin θ
- √(a²+x²): x = a·tan θ
- √(x²-a²): x = a·sec θ
Integrais notáveis:
• ∫xⁿdx = xⁿ⁺¹/(n+1) + C
• ∫eˣdx = eˣ + C
• ∫1/x dx = ln|x| + C
