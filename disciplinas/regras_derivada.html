Regras de Derivação
Regras básicas de derivação:
1. Constante:: d/dx[c] = 0
2. Potência:: d/dx[xⁿ] = nxⁿ⁻¹
3. Soma:: d/dx[f+g] = f' + g'
4. Produto:: d/dx[f·g] = f'·g + f·g'
5. Quociente:: d/dx[f/g] = (f'·g - f·g') / g²
6. Cadeia:: d/dx[f(g(x))] = f'(g(x))·g'(x)
Derivadas importantes:
• d/dx[sin x] = cos x
• d/dx[cos x] = -sin x
• d/dx[eˣ] = eˣ
• d/dx[ln x] = 1/x
• d/dx[tan x] = sec²x
Aplicações: taxa de variação, reta tangente, máximos e mínimos, análise de concavidade.
