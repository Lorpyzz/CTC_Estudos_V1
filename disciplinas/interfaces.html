Aula: Interfaces e Classes Abstratas
Classe Abstrata:
• Não pode ser instanciada
• Pode ter métodos concretos e abstratos
• Usada para compartilhar código entre classes relacionadas
Interface:
• Define um contrato (métodos sem implementação)
• Uma classe pode implementar múltiplas interfaces
• A partir do Java 8: pode ter métodos default e static
Quando usar:
• Classe abstrata: quando há relação "é um" e código compartilhado
• Interface: quando há comportamento comum entre classes não relacionadas
Duração: ~45 minutos
