Herança e Polimorfismo
Herança permite que uma classe (filha) herde atributos e métodos de outra (pai).
public class Animal {
protected String nome;
public void falar() { System.out.println("..."); }
}
public class Cachorro extends Animal {
@Override
public void falar() { System.out.println("Au au!"); }
}
Polimorfismo: objetos de classes diferentes respondem à mesma mensagem de formas diferentes.
Animal a = new Cachorro();
a.falar();
Tipos:
• Polimorfismo de subtipo (herança)
• Polimorfismo paramétrico (generics)
• Sobrecarga (overloading)
Princípio de Substituição de Liskov: objetos de uma classe filha devem poder substituir objetos da classe pai sem alterar o comportamento correto do programa.
