Lista 1 — Tabelas Hash
Exercício 1: Implemente uma tabela hash com tratamento de colisão por encadeamento. Use a função hash h(k) = k mod M.
Exercício 2: Compare empiricamente o desempenho de diferentes funções hash para strings.
Exercício 3: Implemente uma tabela hash com endereçamento aberto (linear probing). Analise o fator de carga.
Exercício 4: Usando tabela hash, implemente um verificador de palavras duplicadas em um texto.
