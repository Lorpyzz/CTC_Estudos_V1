Manipulação de Arquivos em C
A manipulação de arquivos em C utiliza a biblioteca e o tipo FILE*.
Funções principais:
• fopen(nome, modo): abre arquivo ('r' leitura, 'w' escrita, 'a' append)
• fclose(fp): fecha arquivo
• fprintf/fscanf: escrita/leitura formatada
• fgets/fputs: leitura/escrita de strings
• fread/fwrite: leitura/escrita binária
Modos de abertura:
• "r": leitura (arquivo deve existir)
• "w": escrita (cria ou sobrescreve)
• "a": append (adiciona ao final)
• "rb"/"wb": modo binário
Exemplo:
FILE *fp = fopen("dados.txt", "w");
if (fp == NULL) { printf("Erro"); return 1; }
rintf(fp, "Olá, arquivo!\n");
fclose(fp);
