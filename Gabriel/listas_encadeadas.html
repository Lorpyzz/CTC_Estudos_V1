Listas Encadeadas
Listas encadeadas são estruturas de dados lineares onde cada elemento (nó) contém um valor e um ponteiro para o próximo nó.
Tipos:
• Lista simplesmente encadeada: cada nó aponta para o próximo
• Lista duplamente encadeada: cada nó aponta para o próximo e o anterior
• Lista circular: o último nó aponta para o primeiro
Operações básicas (complexidade):
• Inserção no início: O(1)
• Inserção no fim: O(n) ou O(1) com ponteiro para cauda
• Busca: O(n)
• Remoção: O(n)
Vantagens sobre arrays:
• Tamanho dinâmico
• Inserção/remoção eficiente no início
Desvantagens:
• Sem acesso direto por índice
• Uso extra de memória para ponteiros
